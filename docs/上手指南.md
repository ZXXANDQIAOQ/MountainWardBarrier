# 上手指南

写给"从 GitHub 拉下来想跑起来 / 想改点什么"的人。

---

## 一、你需要什么

| 场景 | 需要 |
|---|---|
| 只想玩 | Unity 2022.3 LTS（任意小版本） |
| 想出 Android 包 | 上面的 + Unity 的 Android Build Support（含 SDK/NDK）|
| 只想改数值、不想开 Unity | .NET 8 SDK（跑测试）+ 任意文本编辑器 |
| 想重新生成美术 | Python 3 + Pillow |
| 想重新生成音效 | Python 3（不需要任何第三方库）|

工程版本写在 `ProjectSettings/ProjectVersion.txt`：`2022.3.62f1`。
装了别的 2022.3.x 也没关系，Unity Hub 会问一句要不要用你的版本打开，选是即可。

## 二、第一次打开

1. Unity Hub → **Add** → 选择本目录。
2. 打开工程。首次导入会花一两分钟（58 张贴图 + 22 个音频）。
3. 编辑器脚本 [`Assets/Editor/ProjectBootstrap.cs`](../Assets/Editor/ProjectBootstrap.cs) 会自动：
   - 生成主场景 `Assets/Scenes/Main.unity` 并加进 Build Settings
   - 设置包名、竖屏、最低 SDK 24、ARM64、关闭联网权限
   - 把 `Resources/Sprites` 下的贴图按 Sprite 重新导入（九宫格面板会带上 border）
4. 打开 `Assets/Scenes/Main.unity`，点 **Play**。

如果第 3 步没自动发生（比如首次导入时报了别的错），手动点菜单
**仙侠·护山大阵 → 一键配置工程**。

### 其实不需要场景

游戏入口用 `[RuntimeInitializeOnLoadMethod]` 自启动：

```csharp
[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
private static void AutoBoot() { ... }
```

意思是**任意空场景按 Play 都会起游戏** —— Canvas、相机、EventSystem 全在运行时创建。
主场景里其实只有一个空对象挂在 `GameBootstrap` 上（为了让 Hierarchy 里能看见它）。

## 三、不出 Unity 也能验证

如果你只想改数值或者只想确认代码没坏，不需要打开 Unity：

```bash
# 1) 全工程类型检查（Unity 层也会被编译，靠 tools/UnityStubs 里的 API 桩）
dotnet build tools/UnityCheck/UnityCheck.csproj

# 2) 核心逻辑自测 + 三难度平衡试打（146 项断言）
dotnet run --project tools/CoreTests/CoreTests.csproj
```

第 2 条会打印类似这样的东西：

```
· 数值平衡（脚本机器人试打）
    简单：机器人胜 3/3，平均推进到第 10.0 波，平均耗时 204 秒，平均建阵 21.0 座，平均漏怪 15.0 只
    普通：机器人胜 3/3，平均推进到第 15.0 波，平均耗时 304 秒，平均建阵 24.0 座，平均漏怪 21.0 只
    困难：机器人胜 0/3，平均推进到第 19.3 波，平均耗时 436 秒，平均建阵 27.0 座，平均漏怪 34.7 只
通过 146 项，失败 0 项
```

**改完数值请务必跑一遍第 2 条。** 判据是：简单和普通必须通关，困难至少推进到第 14 波。

## 四、常见改动怎么做

### 改数值（不需要重编译）

编辑 `Assets/Resources/Config/game_config.json`。例如把攻击法阵的伤害从 30 调到 36：

```json
{ "kind": "AttackArray", "displayName": "攻击法阵", "cost": 90, "damage": 36, ... }
```

保存后直接 Play 就生效。字段缺失会保留默认值，写错了只会打一条警告 —— 不会打不开游戏。

改完用 `dotnet run --project tools/CoreTests/CoreTests.csproj` 验一遍。

### 加一种阵法

1. `Core/DataModels.cs` 的 `TowerKind` 枚举里加一项。
2. `Core/DefaultConfig.cs` 的 `BuildTowers()` 里加它的数值。
3. `Assets/Scripts/Unity/BattleScreen.cs` 顶部改 `CardSpiritStart` 等下标常量，
   并调整 `BuildBottomBar` 里的行布局（每行几个）。
4. `tools/gen_sprites.py` 里加一个绘制函数并注册进 `jobs`，跑一次生成图标。
5. 跑 `dotnet build tools/UnityCheck/UnityCheck.csproj` 和核心测试。

### 加一个成就

只需改两处：`Core/SaveData.cs` 里 `Achievements.All` 加一条定义，
`Achievements.Check` 里加一个 `case`。界面（成就面板）会自动多出一行，
因为它是遍历 `Achievements.All` 的。

### 改配色

两处必须同时改：`tools/gen_sprites.py` 的调色板常量（生成美术用）和
`Assets/Scripts/Unity/Palette.cs`（代码画的 UI 用）。它们是同一套十六进制值。

### 重新生成全部美术 / 音效

```bash
python tools/gen_sprites.py      # 58 张 PNG → Assets/Resources/Sprites
python tools/gen_audio.py        # 22 个 WAV → Assets/Resources/Audio
```

生成是确定性的（脚本内固定了随机种子），重复跑不会产生差异。

## 五、打包 Android

菜单 **仙侠·护山大阵 → 一键配置工程** 已经把该配的都配好了：

| 项 | 值 | 在哪 |
|---|---|---|
| 包名 | `com.qiaoqiao.mountainwardbarrier` | `ProjectBootstrap.ApplyAndroidSettings` |
| 版本 | 1.0.0 / versionCode 1 | 同上 |
| 屏幕 | 竖屏锁定 | `ApplyPlayerSettings` |
| 最低 SDK | 24（Android 7.0） | `ApplyAndroidSettings` |
| 架构 | 仅 ARM64 + IL2CPP | 同上 |
| 权限 | **关闭联网与外部存储权限** | 同上 |
| 色彩空间 | Gamma | `ApplyGraphicsSettings` |

然后 `File → Build Settings → Android → Build`。

> **为什么只出 ARM64？** Google Play 要求 64 位；而且只出一个架构能把包体压下来。
> 如果你想在自己 32 位的老设备上装，把 `targetArchitectures` 改成 `ARMv7 | ARM64`。

> **关掉联网权限是刻意的。** 游戏没有任何网络代码，关掉之后系统层面也不给它联网能力 ——
> 这是"无联网请求"这句话的技术保证，而不是一句宣传语。

## 六、踩过的坑（省得你再踩一遍）

**1. `ProjectSettings/` 和 `.meta` 不在仓库里。**
这是刻意的（机器生成、易冲突）。所有必要设置都由 `ProjectBootstrap.cs` 写入。
如果你改了 PlayerSettings 并希望团队共享，请把改动**写进那个脚本**，而不是只改编辑器里的值。

**2. `*.csproj` 只忽略根目录。**
Unity 会在工程根目录生成 `Assembly-CSharp.csproj` 之类的文件（已忽略），
但 `tools/CoreTests/CoreTests.csproj` 和 `tools/UnityCheck/UnityCheck.csproj` 是**手写**的，必须提交。
`.gitignore` 里用的是根锚定的 `/*.csproj`，别改成全局 `*.csproj`。

**3. 枚举不能和整数隐式互转。**
C# 里 `int x = SomeEnum.A;` 是编译错误，必须写 `(int)`。
开发中在卡牌下标计算那块就踩过一次，现在已经改成用三个重载而不是传 `int`。

**4. `UnityEngine.Object` 的 `==` 被重载过。**
`obj == null` 对"已被 Destroy 的对象"返回 true，而 `obj is null` / `ReferenceEquals` 不会。
销毁对象后请统一用 `== null` 判断。

**5. 中文字体不能靠 Unity 内置字体。**
内置 Arial / LegacyRuntime 都不含中文字形，直接用会显示成方块。
`UiKit.GetFont()` 已经做了系统字体降级链，但如果你看到方块，先检查那里的候选字体名列表。

**6. 贴图导入设置会影响 9 宫格。**
`ui_panel` / `ui_bar_*` 依赖 `TextureImporter.spriteBorder` 才能用 `Image.Type.Sliced`。
如果面板圆角被拉变形了，说明 border 丢了 —— 用菜单
**重新导入全部美术资源**，或检查 `SpriteImportPostprocessor` 里的路径匹配。
