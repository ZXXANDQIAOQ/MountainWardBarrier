# 需求实现对照

对照《仙侠·护山大阵》需求文档 V3.0 逐条核对的实现情况。
每一行都给出**代码位置**，方便审查时直接跳过去看。

---

## 一、世界观与呈现

| 需求 | 实现 | 位置 |
|---|---|---|
| 仙侠题材，护山大阵的设定 | 妖魔沿两条山路攻向山门，玩家布阵御敌 | `Core/DefaultConfig.cs`（棋盘与波次）、`Unity/BoardView.cs`（棋盘绘制） |
| 竖屏手机端 | CanvasScaler 参考分辨率 1080×1920，match 0.5；PlayerSettings 锁竖屏 | `Unity/GameBootstrap.cs`、`Editor/ProjectBootstrap.cs` |
| 中国风视觉 | 玉青 + 鎏金（我方）对暗紫 + 妖红（敌方）的统一调色板 | `tools/gen_sprites.py`、`Unity/Palette.cs` |
| 背景音乐与音效 | 2 首 BGM + 20 个音效，BGM 交叉淡入 | `tools/gen_audio.py`、`Unity/AudioLibrary.cs` |

## 三、妖魔与波次

| 需求 | 实现 | 位置 |
|---|---|---|
| 小妖 | 90 血，数量压制型 | `Core/DefaultConfig.cs` `BuildEnemies()` |
| 妖将 | 260 血，**死亡分裂**（Split） | 同上，逻辑在 `BattleSimulation` 的分裂判定 |
| 大妖 | 520 血，带 240 点**护盾**（Shield） | 同上，护盾再生在模拟层 |
| 魔君（BOSS） | 2200 血，半血**狂暴**（Frenzy）加速并加攻 | 同上 |
| 妖魔会攻击阵法 | 射程内拆阵，攻击间隔与伤害按种类区分 | `Core/Entities.cs`、`BattleSimulation.Tick` |
| 三档难度：简单 / 普通 / 困难 | 10 / 15 / 20 波，血量·速度·灵气·耐久四维区分 | `Core/DefaultConfig.cs` `BuildDifficulties()` |
| 每 5 波一个 BOSS 波 | 第 5/10/15/20 波为 BOSS 波，清波奖励显著提高 | `Core/DefaultConfig.cs` `BuildWaves()` |
| 波次间有备战期 | 首波 12 秒，常规 7–10 秒，BOSS 波前 10–14 秒 | 同上（`prepTime`） |
| 下一波阵容预告 | HUD 右侧显示下一波的种类、数量与血量倍率 | `Unity/BattleScreen.cs` `PreviewLabel()` |
| 波次奖励 | 每波清完给额外灵气，BOSS 波更多 | `Core/DefaultConfig.cs`（`clearBonus`） |

## 五、系统功能

| 需求 | 实现 | 位置 |
|---|---|---|
| 本地存档 | PlayerPrefs 存 JSON，含纪录、成就、统计与全部设置 | `Unity/SaveSystem.cs`、`Core/SaveData.cs` |
| 成就系统 | 10 个成就，纯函数判定，可脱离 Unity 测试 | `Core/SaveData.cs` `Achievements` |
| 排行（最高纪录） | 各难度的最高波次与最快通关时间，主界面难度卡上展示 | `Core/SaveData.cs`、`Unity/MenuScreen.cs` |
| 结算界面 | 胜负、波次、耐久、斩妖漏怪、构筑、灵气收支、伤害、技能、耗时、新成就 | `Unity/ResultScreen.cs` |
| 设置界面 | 音乐/音效开关与音量、伤害飘字、帧率显示、重看引导、抹除记录 | `Unity/Overlays.cs` `Settings()` |
| 游戏内手册 | 「典籍」面板列出阵/灵/符/法/妖魔/难度的完整数值 | `Unity/Overlays.cs` `Codex()` |
| 无广告 | 不集成任何广告 SDK | 工程无第三方依赖 |
| 无内购 | 无商城、无付费点、无货币 | 同上 |
| 无联网 | 关闭 Android 联网权限；代码无任何网络调用 | `Editor/ProjectBootstrap.cs` `ApplyAndroidSettings` |

## 六、工程与交付

| 需求 | 实现 | 位置 |
|---|---|---|
| 资源自备（图片 / 音效） | 全部程序化生成，无第三方素材 | `tools/gen_sprites.py`、`tools/gen_audio.py` |

## 七、明确未做的部分

以下是在需求讨论中**刻意排除**的，不是遗漏：

| 项目 | 原因 |
|---|---|
| 联网排行榜、云存档 | 与"单机、无联网请求"的定位冲突 |
| 存档唯一性校验 / 反作弊 | 单机游戏，玩家想改存档是他自己的自由 |
| 背景音乐切换播放列表 | 两首 BGM 已经够用，多一首的收益不抵成本 |
| iOS 打包配置 | 需求只提了安卓；代码本身是跨平台的，但没配 iOS 所需的签名与图标 |
