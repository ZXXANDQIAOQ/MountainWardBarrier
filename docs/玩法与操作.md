# 玩法与操作

## 一、目标

妖魔从棋盘上方两条山路进场，沿路走到下方山门。

- **山门耐久归零 → 山门失守**（失败）
- **撑满全部波次而山门未破 → 守山成功**（胜利）

三个难度的波数：简单 10 波、普通 15 波、困难 20 波。每 5 波是 BOSS 波。

---

## 二、操作

| 动作 | 怎么做 |
|---|---|
| 布置阵法 | 点阵法卡选中 → 点空地落子 |
| 拖拽布置 | **按住卡牌拖到棋盘上松手**（拖拽超过 18 像素才算拖，否则当点击） |
| 放置仙灵 / 符箓 | 同上，但只能落在**道路**格子上 |
| 选中已建的阵法 | 点一下它，弹出操作面板（升级 / 铲除） |
| 施放终极技 | 直接点技能卡，立即生效，有独立冷却 |
| 提前开战 | 备战期点「开始」 |
| 暂停 | 右上角暂停按钮（备战说明也一起暂停） |
| 二倍速 | 右上角倍速按钮，1× ⇄ 2× |
| 返回 | 安卓返回键逐层退出：弹窗 → 取消选中 → 再按一次返回山门 |

布置时有半透明预览：**绿色=可以放，红色=不行**（格子被占 / 不是道路 / 灵气不足）。

---

## 三、三类布置物

### 阵法（放在空地）

| 阵法 | 作用 | 什么时候该有它 |
|---|---|---|
| 聚灵阵 | 每秒产 2 点灵气 | 开局立刻铺，是整局的经济基础 |
| 攻击法阵 | 单发 30 伤害，射程 2.6 格 | 第 1 波前就要有第一座 |
| 困阵 | 范围内妖魔速度降到 50% | 阵线成型后优先补，它让所有输出的实际收益翻倍 |
| 幻阵 | 范围内 25% 概率让攻击落空 | 对面出现大妖（会拆阵）时用来保前排 |
| 护盾阵 | 200 点护盾池，替周围阵法挨打 | 中后期保护关键格 |

### 仙灵（放在道路）

会自己找目标打，有存在时间（到点自行消散）。

- **剑灵**：240 血近战，唯一能正面堵路的单位
- **符灵**：远程 + 溅射，脆但输出位置安全
- **丹灵**：不攻击，每秒修 2 点山门耐久 —— 困难难度的救命稻草

### 符箓（放在道路）

埋下去看不见，妖魔踩到才触发，一次性。

- **雷符**：40 灵气换 160 单体伤害，点杀带护盾的大妖最划算
- **冰符**：减速到 35%、持续 5 秒，给阵线买时间
- **爆符**：240 点范围伤害，专治密集冲锋

## 四、终极技

| 技能 | 效果 | 冷却 |
|---|---|---|
| 天雷咒 | 全屏 380 伤害 | 45 秒 |
| 冰封 | 全屏强减速 5 秒 | 50 秒 |
| 灵雨 | 修复 25% 山门耐久 + 120 点范围伤害 | 40 秒 |

三者冷却独立，理论可以连放，但要付得起灵气。

## 五、节奏

一局的时间线是这样的：

```
[备战]──开始/倒计时──►[第 N 波]──全部清完──►[清波奖励 + 下一波预告]──►[备战]──► ...
                                    │
                                    └─ 有妖魔摸到山门 → 掉耐久（会震屏 + 红字）
```

- **备战期**：可以在棋盘上任意布置。顶部会预告**下一波的阵容、总数、血量倍率** ——
  这一条信息很重要，"看到下一波是 41 只小妖"和"看到下一波是 3 只大妖"是两种完全不同的准备。
- **交战中**：仍然可以布置和升级，只是没有预告可看。
- **清波奖励**：每波清完给一笔额外灵气（BOSS 波给得更多，第 20 波 260）。

### 什么时候会用到的几个判断

- 灵气不足时，**先补聚灵阵**而不是硬堆攻击法阵 —— 攻击法阵再多也没钱放。
- 困阵是**乘法增益**：它让妖魔在射程内停留更久，等于放大所有输出的实际价值。
- 第 9 / 12 / 19 波是数量峰（18 / 21 / 41 只），这几波前留一张爆符或天雷咒。
- BOSS 带护甲，**百分比减伤意味着堆伤害不如先削**；雷符和天雷咒是主要解法。
- 大妖会拆阵（40 点拆阵伤害），所以前排别只堆一个关键法阵，用护盾阵罩住。

## 六、成就（10 个）

| 成就 | 条件 |
|---|---|
| 初入山门 | 完成第一场对局 |
| 守山有功 | 通关简单难度 |
| 中流砥柱 | 通关普通难度 |
| 力挽狂澜 | 通关困难难度 |
| 固若金汤 | 以 90% 以上的山门耐久通关 |
| 灵气大亨 | 单局累计获得 6000 点灵气 |
| 五行俱全 | 单局里布置齐全部 5 种阵法 |
| 一尘不染 | 通关且没有任何妖魔抵达山门 |
| 雷动九天 | 单局使用天雷咒 3 次 |
| 百战之身 | 累计完成 30 场对局 |

成就的判定是**纯函数**（存档 + 本局战报 → 是否达成），所以它可以在没有 Unity 的环境里被测试，
也不会因为"先点了成就界面再打"之类的顺序问题出错。

## 七、界面

| 界面 | 内容 |
|---|---|
| 山门（主界面） | 三张难度卡（带各自的最佳波次/最快通关）、总统计、四个入口：设置 / 成就 / 典籍 / 关于 |
| 对局界面 | 顶部 HUD（灵气、波次、山门耐久、下一波预告）、中部棋盘、底部三行卡牌、BOSS 血条行 |
| 结算界面 | 胜负、推进波次、耐久、斩妖/漏怪、构筑统计、灵气收支、总伤害、技能次数、耗时、新解锁成就 |
| 典籍 | 阵 / 灵 / 符 / 法 / 妖魔 / 难度 的完整数值与说明 —— 相当于游戏内的手册 |
| 设置 | 音乐与音效开关+音量、伤害飘字、帧率显示、重看引导、抹除记录（二次确认） |
| 新手引导 | 4 页图文，首次进游戏自动弹出，随时可从设置重看 |

## 八、存档

存在 `PlayerPrefs`（安卓上就是应用私有目录），内容是纯逻辑层序列化出来的 JSON 字符串。

会保存的内容：各难度最高波次与最快通关时间、已解锁成就、对局/胜负/击杀/灵气/时长累计、
引导是否看过、音量与开关偏好、上次选择的难度。

**没有任何账号、没有云同步、没有联网请求。** 卸载应用即清除全部记录。

设置里的「抹除山门记录」会清空以上全部内容（带一次确认弹窗）。

## 九、一些刻意的"不"

- 不做广告、不做内购、不做体力、不做抽卡
- 不做每日任务、不做签到 —— 单机游戏不该有留存压力
- 不做云存档与排行榜
- 不弹"评价求好评"弹窗
